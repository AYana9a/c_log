# 心理機能ログ解析 (MBTI Cognitive Function Analyzer)

LINE / Discord のトーク履歴から、ユング心理学ベースの「心理機能(認知機能)」の傾向を分析し、MBTIタイプを推定するWebアプリです。

2つの解析方式があります。
- **ローカル解析**(デフォルト): すべての処理がブラウザ内で完結し、ログの内容はどこにも送信されません。ただし、キーワード頻度に基づく簡易的な方式のため、口語のフィラーや会話の話題・テンポといった個人の性格以外の要因に結果が引っ張られやすい傾向があります。
- **AI解析**: 選択した話者の発言(相手の発言は含まない)を、ユーザー自身のAnthropic APIキーでClaude APIに送信し、文脈を理解した分析を行います。話し相手や話題が変わっても結果が安定しやすくなりますが、その分だけメッセージ内容が外部に送信されます。APIキーはブラウザのlocalStorageにのみ保存されます。

## 使い方

ビルド不要の静的サイトです。ローカルで開く場合はESモジュールを使っているため、簡易HTTPサーバー経由でアクセスしてください。

```sh
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

1. LINE または Discord からエクスポートしたトーク履歴(.txt)をペースト、またはファイルとして読み込む
2. 「ログを解析する」を押す
3. 分析したい話者を1人選び、解析方式(ローカル解析 / AI解析)を選ぶ。AI解析の場合はAnthropic APIキーを入力する
4. 「この人を分析する」を押すと、心理機能レーダーチャートと推定タイプが表示される

対応フォーマット:
- **LINE**: `HH:MM\t名前\tメッセージ` のタブ区切り形式(トーク履歴のテキスト書き出し)
- **Discord**: `[YYYY/MM/DD HH:MM] 名前` ヘッダー形式(DiscordChatExporter等のプレーンテキスト出力)
- **汎用**: `名前: メッセージ` 形式のシンプルなコピペにも対応

## 心理機能理論について

ユング心理学に基づくMBTI理論では、人の心の働きを8つの「心理機能」で説明します。

| 知覚機能 | 判断機能 |
|---|---|
| Se(外向感覚) | Te(外向思考) |
| Si(内向感覚) | Ti(内向思考) |
| Ne(外向直観) | Fe(外向感情) |
| Ni(内向直観) | Fi(内向感情) |

各タイプは4つの機能が「主機能→補助機能→第三機能→劣勢機能」の順で並ぶ「機能スタック」を持ちます(例: INTJ = Ni-Te-Fi-Se)。詳細は `js/functions.js` の `FUNCTION_INFO`、`js/mbti.js` の `TYPE_STACKS` を参照してください。

## 分析ロジック

### ローカル解析(キーワード方式)

1. 選択した話者の全メッセージに対して、8機能それぞれに対応する日本語の語彙・言い回し(`js/functions.js` の `KEYWORDS`)の出現をスコアリング
2. メッセージ長・感嘆符・疑問符の出現率など文体的な特徴も加点
3. メッセージ数で正規化し、8機能間で相対的な強弱(0-100)に変換
4. 16タイプそれぞれの機能スタックに対して、位置(主機能〜劣勢機能)に応じた重み付き適合度を計算し、最も適合度の高いタイプを推定タイプとして表示

「かも」「というか」「大丈夫」のような口語の相槌・ヘッジ表現は、カジュアルな会話では話者の心理機能によらずほぼ全員が高頻度で使うため、除外するか大きく重みを下げてある。それでも、キーワード頻度は個人の性格そのものよりも会話の話題やテンポに左右されやすいという原理的な限界があり、同じ人物でも会話相手や話題が変わると結果がぶれることがある。

### AI解析(Claude API)

1. 選択した話者の発言のみ(相手の発言は含めない)を、メッセージ数が多い場合は時系列全体から均等にサンプリングして文字数上限(`js/ai.js` の `MAX_INPUT_CHARS`)内に収める
2. 8機能の定義とともにClaude APIに送信し、「会話相手と比べた相対評価ではなく、一般的な行動パターンとしての絶対評価」で0〜100のスコアを付けるよう指示する
3. 返ってきたスコアをそのまま使い、ローカル解析と同じ機能スタック照合ロジック(`js/mbti.js`)でタイプを推定する

APIキーはユーザー自身のものを使う(BYOK)方式で、ブラウザから直接 `https://api.anthropic.com/v1/messages` を呼び出す。このアプリ自体にサーバーは存在しないため、キーやログの内容が開発者を含め誰かを経由することはない。

## 免責事項

これは会話文中の言葉遣いや文体の傾向から心理機能の可能性を推定する簡易的なヒューリスティック分析であり、心理学的に検証された診断ツールではありません。参考・エンタメとしてご利用ください。

## ファイル構成

```
index.html          UIのエントリーポイント
css/style.css        スタイル
js/app.js            UIロジック・イベントハンドリング
js/parser.js         LINE/Discord/汎用ログのパーサー
js/functions.js      心理機能の定義・キーワード辞書・スコアリング(ローカル解析)
js/ai.js             Claude APIを使った意味理解ベースの分析(AI解析)
js/mbti.js           16タイプの機能スタック定義・タイプマッチング
js/radar.js          依存ライブラリなしのSVGレーダーチャート描画
```
